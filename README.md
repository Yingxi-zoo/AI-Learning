# AI-Learning

记录我在 AI 相关技术上的学习过程。

最后更新：2026-09-23

## 关于这个仓库

这是我的个人学习仓库，用来整理和沉淀对 AI 领域主流技术的理解。内容围绕当前
AI 工程实践中常见的协议、工具与概念展开，比如 MCP、A2A、Agent、Function
Calling、Skill，以及 Claude Code 这类工具的实际使用。

每篇笔记都是我在阅读官方文档和一手资料之后，按自己的理解重新梳理的产物。
写下来的目的不是产出教程，而是把学到的东西讲清楚一遍——讲不明白的地方，
往往就是还没真正理解的地方。

## 内容来源

- 以官方文档、协议规范和项目仓库为主要依据（如 MCP 官方规范、A2A 官方规范、
  Anthropic 官方文档等）
- 涉及概念解释时，尽量追溯到一手资料，而不是二手转述
- 重要结论尽量标注资料出处，方便回头核对

需要说明的是，这些笔记记录的是我当前阶段的理解，不是权威参考，也难免存在
偏差和过时之处。如果发现错漏，欢迎指出。
